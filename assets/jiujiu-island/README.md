# 啾啾岛素材库

品牌升级（点点手帐 → 啾啾岛）用的插画素材。改 UI 时从这里取图。

- `web/`：给 App 用的压缩版（webp，透明背景已保留），全部加起来约 600KB。页面里直接引用这里的文件。
- `source/`：ChatGPT 生成的原图（png，约 1–2MB 一张）。以后要重新裁切、放大或导出物料时用，不要直接放进页面。

画风：日系绘本，彩铅加淡水彩，细深棕线条，米色纸底。主色：叶绿、珊瑚红、浅粉、奶油米、浅海青。

## 啾啾

| 文件 | 内容 | 建议用在 |
|---|---|---|
| `jiujiu-flower` | 啾啾在花旁悬停（定稿形象） | 关于页、App Store 介绍图 |

| `jiujiu-sleep` | 蜷成一团打盹 | 今日页空状态 |
| `jiujiu-nest` | 坐在蛛丝苔藓巢里 | 侧栏头部、邮票、「我的岛」 |
| `jiujiu-postcard` | 叼着明信片飞回来 | 惊喜入口（表情待重做：现在是半眯眼） |

## 场景

| 文件 | 内容 | 建议用在 |
|---|---|---|
| `splash` | 啾啾叼叶子飞过小岛，下方留白 | 开机画面（标题放下方留白处） |

| `postcard-food-seaside` | 傍晚海边亮灯的小饭馆 | 明信片正面（美食类回忆） |

## 注意

- `sw.js` 会把联网时加载过的图片自动存进缓存，所以图片在联网打开过一次后，离线也能显示。如果要保证装好后第一次就离线可用（比如开机画面），就把它加进 `sw.js` 的预缓存清单，并升级缓存名。
- 换图标类素材时沿用老规矩：换内容就换文件名或加 `?v=`，避免 iOS 缓存旧图。
